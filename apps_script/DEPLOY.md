# 응답 수집 서버 만들기 (Google Apps Script, 약 2분)

구글 계정만 있으면 됩니다. 새로 가입할 필요 없고, 결제도 없습니다.
끝나면 응답이 **본인 구글 스프레드시트**에 자동으로 쌓입니다. 외부 서비스를 거치지 않습니다.

---

## 1. 프로젝트 만들기

1. https://script.google.com 접속 (응답을 받을 구글 계정으로 로그인된 상태여야 합니다)
2. 왼쪽 위 **`+ 새 프로젝트`** 클릭
3. 가운데 코드창에 이미 들어 있는 내용(`function myFunction() {...}`)을 **전부 지우기**
4. **코드 전체를 복사해서 붙여넣기.** 둘 중 편한 쪽으로 여세요.
   - 내 컴퓨터의 파일: `Science_benchmark/mold_survey/apps_script/Code.gs` (에디터에서 열어 전체 선택 → 복사)
   - 웹: https://github.com/yerimoh/mold_survey/blob/main/apps_script/Code.gs (오른쪽 위 복사 아이콘)
5. `Ctrl+S` (맥은 `⌘+S`)로 저장. 프로젝트 이름을 물으면 아무거나 (예: `mold_survey_collector`)

## 2. 웹 앱으로 배포하기

6. 오른쪽 위 파란 **`배포`** → **`새 배포`**
7. 왼쪽 **톱니바퀴(유형 선택)** → **`웹 앱`** 선택
8. 세 칸을 이렇게 둡니다
   - 설명: 아무거나 (비워도 됨)
   - **다음 사용자로 실행: `나`**
   - **액세스 권한이 있는 사용자: `모든 사용자`** ← 이게 제일 중요합니다
9. **`배포`** 클릭

## 3. 권한 승인 (처음 한 번만, 경고 화면이 정상입니다)

10. **`액세스 승인`** → 본인 계정 선택
11. **"Google에서 확인하지 않은 앱입니다"** 경고가 뜹니다. 본인이 방금 만든 코드라 정상입니다.
    → 왼쪽 아래 **`고급`** → **`mold_survey_collector(안전하지 않음)으로 이동`** → **`허용`**

## 4. 주소 복사해서 확인

12. 화면에 나오는 **웹 앱 URL**을 복사합니다. `https://script.google.com/macros/s/AKfy……/exec` 형태입니다.
13. 그 주소를 브라우저 새 탭에 붙여넣어 보세요. 아래처럼 나오면 성공입니다.
    ```json
    {"ok":true,"service":"mold_survey collector"}
    ```
14. 이 URL을 알려주시면 `config.js`에 넣고 실제 제출 테스트까지 해 드립니다.
    직접 넣으시려면 [`config.js`](../config.js)의 `ENDPOINTS` 안 A 줄의 주석을 풀고 `url`에 붙여넣은 뒤 push하면 됩니다.

## 코드를 고친 뒤 반영하기 (문항이 바뀌었을 때)

`Code.gs`가 바뀌면 **붙여넣기만으로는 반영되지 않습니다.** 새 버전으로 다시 배포해야 합니다. URL은 그대로입니다.

1. https://script.google.com → 해당 프로젝트 열기
2. 코드창 내용을 전부 지우고 최신 코드 붙여넣기
   (`mold_survey/apps_script/Code.gs` 또는 https://github.com/yerimoh/mold_survey/blob/main/apps_script/Code.gs )
3. `Ctrl+S` 저장
4. **`배포` → `배포 관리` → 연필(수정) → `버전`을 `새 버전`으로 → `배포`**
5. 웹 앱 URL을 새로고침해 확인. **`"schema":97` 이 보이면 최신 코드가 반영된 것**입니다.
   `{"ok":true,"service":...}` 만 나오고 schema가 없으면 아직 예전 코드가 서비스 중입니다(4번을 다시 하세요).

열 구성이 바뀌면 기존 `responses` 탭은 `responses_old_<날짜시각>` 으로 **자동 보관**되고,
새 헤더로 새 탭이 만들어집니다. 예전 응답은 지워지지 않습니다.

## 자주 걸리는 곳

| 증상 | 원인과 해결 |
|---|---|
| URL을 열면 **구글 로그인 화면**이 뜨거나, **"페이지를 찾을 수 없음 / 현재 파일을 열 수 없습니다"** | 가장 흔한 경우입니다. 8단계의 **`액세스 권한이 있는 사용자`가 `모든 사용자`가 아닙니다.** 고치는 법: 오른쪽 위 `배포` → **`배포 관리`** → 해당 배포의 **연필(수정)** → `액세스 권한이 있는 사용자`를 **`모든 사용자`**로 바꾸고 `배포`. 이렇게 고치면 **URL은 그대로 유지**됩니다. |
| `액세스 권한`에 **"모든 사용자"가 안 보이거나 선택이 안 됨** | 학교/회사 워크스페이스 계정은 외부 공개가 정책으로 막혀 있을 수 있습니다. 개인 gmail 계정으로 1~3단계를 다시 하세요. 조직 내부만 허용되면 외부 응답자는 제출할 수 없습니다. |
| URL이 `/dev`로 끝남 | 그건 테스트용이라 외부에서 안 됩니다. 반드시 **`/exec`**로 끝나는 주소를 쓰세요. |
| 열었더니 `{"ok":true}`가 아니라 로그인 화면 | 8단계의 액세스 권한이 "모든 사용자"가 아닙니다. `배포 관리`에서 수정하세요. |
| 코드를 고친 뒤 반영이 안 됨 | `배포 관리` → 연필(수정) → 버전 `새 버전` → `배포`. 새로 만들면 URL이 바뀝니다. |

## 배포한 뒤 생기는 것들

- **`mold_survey_responses` 스프레드시트** (내 드라이브에 자동 생성)
  - `responses` 탭: 응답 본문 전체. 이메일은 여기 없습니다.
  - `emails` 탭: 접수번호 ↔ 이메일. **보상 지급이 끝나면 이 탭만 지우면 개인정보 폐기 완료**입니다.
- **`mold_survey_uploads` 폴더**: 응답자가 올린 스크린샷 (접수번호가 파일명 앞에 붙습니다)

메일 전송 경로(FormSubmit)는 지워지지 않고 **백업으로 남습니다**. 이 서버가 잠시 죽어도 응답은 메일로 들어옵니다.
